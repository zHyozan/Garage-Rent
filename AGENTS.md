# Instruções do projeto

- Faça todas as alterações exclusivamente na branch `main`.
- Não crie nem utilize branches alternativas para novas alterações.
- Ao concluir e validar as alterações solicitadas, faça commit e push para `origin/main` automaticamente, conforme autorizado pelo usuário.
- Preserve alterações existentes e não utilize force push para contornar divergências no histórico.
